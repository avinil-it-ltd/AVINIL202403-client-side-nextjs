# 3P Communication - Next.js 14 Frontend

This repository contains the Next.js 14 (App Router) version of the 3P Communication web platform.

## Features

- **Framework**: Next.js 14.2 (App Router) with React 18
- **Styling**: Bootstrap 5, React-Bootstrap, Styled Components, and custom CSS
- **SEO & Metadata**: Optimized SSR meta tags across all public pages
- **Fast Performance**: Static generation and automatic code-splitting
- **Dashboard**: Secure administrative dashboard for project, career, testimonial, and headline management

## Getting Started

### Prerequisites

- Node.js 18.x or 20.x
- npm

### Installation

```bash
npm install --legacy-peer-deps
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or your designated port) in your browser.

### Production Build

```bash
npm run build
npm start
```

## Deployment

This project is optimized for deployment on [Vercel](https://vercel.com).
